# Source pack: practical dorm-friendly guidance (shared)

**RESEARCH ONLY. No guide text.** This is **practical safety guidance, not cultural claims**, and it is the part of each guide where wrong advice could cause harm (fire, housing violations). Housing rules differ by campus, so every guide must say "check your housing contract" and must not promise that any item is allowed. All access dates 2026-11-07. ## 3. Flags and questions

- **Housing rules vary and change:** every figure above is from a page read on 2026-11-07; policies are revised each year.
- **Georgia Tech's section XIII is unverified** (summary only). Read it in a browser before using it; the same for Emory, UGA's housing contract and any campus named in a guide.
- **Naming specific colleges in a public guide:** quoting that "UGA prohibits LED string lights" would be a time-sensitive factual claim about an institution. Recommended: describe the pattern ("some campuses ban string lights as well as flames") and tell students to check their own housing contract (README question 7).
- **Not a substitute for fire-safety expertise:** if the owner wants authoritative general advice, add an NFPA or local fire-marshal source (the NFPA page could not be read).
